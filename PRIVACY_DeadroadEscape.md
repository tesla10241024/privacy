# DeadroadEscape 隐私政策 / Privacy Policy

生效日期 / Effective date：2026-11-09  
最后更新 / Last updated：2026-11-09

## 简体中文

### 1. 适用范围

本隐私政策适用于由 Yongfang Zheng（以下简称“开发者”）提供的游戏 **DeadroadEscape（末路突围）**（以下简称“本游戏”）。

### 2. 数据收集

本游戏不会收集、上传、出售或与开发者共享个人数据。当前版本没有账号系统、开发者运营的服务器、广告、应用内购买、第三方分析、第三方崩溃上报、跨 App 跟踪、云存档、排行榜或联网游戏功能。

本游戏不会请求或读取通讯录、照片、相机、麦克风、精确位置、日历、健康数据、蓝牙数据或广告标识符。

### 3. 设备本地数据

为了保存游戏进度和设置，本游戏会在设备的应用专属存储空间中保存以下数据：

- 零件余额、已解锁关卡和通关状态；
- 当前选择的车辆和车辆升级等级；
- 各关卡的最佳行驶距离；
- 音量和界面语言设置；
- 用于确保首次奖励只结算一次的本地状态。

这些数据不包含姓名、电子邮箱、电话号码、账号、精确位置或其他直接身份信息。数据不会由本游戏发送给开发者或第三方。删除本游戏通常会删除其本地数据；如果设备系统备份包含本游戏数据，恢复行为由 Apple 和用户的系统备份设置决定。本游戏本身不提供开发者运营的云同步服务。

### 4. 系统与引擎访问

本游戏使用 Godot 引擎。为了正常运行、保存文件和管理设备资源，应用及引擎可能在设备本地访问文件时间戳、系统启动时间和可用磁盘空间。此类访问仅用于应用功能，不用于识别用户、跟踪用户或向开发者收集数据。

### 5. 第三方服务与 Apple

本游戏未集成广告、分析、社交登录或其他会向第三方发送游戏数据的 SDK。通过 App Store 下载、更新或诊断本游戏时，Apple 可能根据用户的设备设置和 Apple 自身的隐私政策处理相关信息；该处理由 Apple 控制，并非由本游戏直接收集。

### 6. 儿童隐私

本游戏不会有意收集任何用户（包括儿童）的个人数据。如果未来版本增加数据收集功能，开发者将在启用前更新本政策并提供必要的告知或同意机制。

### 7. 数据安全与保留

由于本游戏不会把游戏进度传输到开发者服务器，相关数据保留在设备的应用沙盒中，并受 iOS 系统安全机制保护。数据通常会一直保留到用户删除本游戏或清除相关设备数据为止。

### 8. 政策变更

如果本游戏将来加入联网功能、账号、广告、分析、云存档或其他会改变数据处理方式的功能，开发者会更新本政策和生效日期。重大变化会通过适当方式告知用户。

### 9. 联系方式

开发者：Yongfang Zheng  
联系渠道：请通过本游戏 App Store 产品页面中的“App 支持”链接联系开发者。

## English

### 1. Scope

This Privacy Policy applies to **DeadroadEscape**, also presented as **末路突围** in Simplified Chinese (the “Game”), provided by Yongfang Zheng (the “Developer”).

### 2. Data Collection

The Game does not collect, upload, sell, or share personal data with the Developer. The current version has no account system, Developer-operated server, advertising, in-app purchases, third-party analytics, third-party crash reporting, cross-app tracking, cloud saves, leaderboards, or online gameplay.

The Game does not request or access contacts, photos, camera, microphone, precise location, calendars, health data, Bluetooth data, or advertising identifiers.

### 3. Data Stored on the Device

To preserve game progress and preferences, the Game stores the following information in its private storage area on the device:

- earned parts, unlocked stages, and completion status;
- the selected vehicle and vehicle upgrade levels;
- best distance for each stage;
- volume and interface language preferences; and
- a local flag used to prevent the first-run reward from being granted more than once.

This information does not include a name, email address, phone number, account, precise location, or another direct identifier. The Game does not transmit this information to the Developer or third parties. Deleting the Game normally removes its local data. If an operating-system backup contains the Game's data, restoration is controlled by Apple and the user's system backup settings. The Game does not provide Developer-operated cloud synchronization.

### 4. System and Engine Access

The Game is built with the Godot engine. To run, save files, and manage device resources, the app and engine may access file timestamps, system boot time, and available disk space locally on the device. These accesses support app functionality only and are not used to identify or track users or to collect data for the Developer.

### 5. Third-Party Services and Apple

The Game does not integrate advertising, analytics, social sign-in, or other SDKs that send gameplay data to third parties. When the Game is downloaded, updated, or diagnosed through the App Store, Apple may process related information according to the user's device settings and Apple's own privacy policies. That processing is controlled by Apple and is not direct collection by the Game.

### 6. Children's Privacy

The Game does not knowingly collect personal data from any user, including children. If a future version introduces data collection, the Developer will update this policy and provide any required notice or consent mechanism before enabling that collection.

### 7. Data Security and Retention

Because the Game does not transmit game progress to a Developer server, relevant data remains in the app sandbox and is protected by iOS security mechanisms. It normally remains there until the user deletes the Game or removes the corresponding device data.

### 8. Changes to This Policy

If a future version adds online features, accounts, advertising, analytics, cloud saves, or another feature that changes data handling, the Developer will update this policy and its effective date. Material changes will be communicated through an appropriate method.

### 9. Contact

Developer: Yongfang Zheng  
Contact: Please use the “App Support” link on the Game's App Store product page to contact the Developer.
