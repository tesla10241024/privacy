# PulseHarbor privacy summary

## App Store privacy answer

**Data Not Collected** for PulseHarbor 1.0.

## Technical basis

- Imported audio is copied only into the app’s local Application Support directory.
- Music-library access uses Apple’s system permission and picker. PulseHarbor stores only the selected item’s persistent identifier, title and artist locally so the user can reopen it.
- The app has no account, analytics, advertising, tracking, telemetry, remote API or third-party network SDK.
- Sharing sends only the track title and artist through the system share sheet after an explicit user action.
- The app does not request contacts, location, microphone, camera, Bluetooth, health or broad photo-library access.

If cloud sync, crash reporting, remote artwork, accounts or analytics are added, the App Store privacy answers must be reviewed before release.
